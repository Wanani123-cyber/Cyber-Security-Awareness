# Cyber-Security-Awareness
A cybersecurity awareness project covering phishing, password security and safe online practices.
# 🛡️ Cybersecurity Baseline Checklist

## Overview
This repository contains a comprehensive cybersecurity baseline checklist designed for employees, students, and junior analysts to maintain essential digital security hygiene. 

## Project Structure
- `README.md`: Project overview and documentation.
- `checklist.md`: Operational security checklist.
- `incident_response_notes.txt`: Quick-reference incident reporting guidelines.

## Usage
Review the checklist periodically to ensure system, account, and operational security controls remain active.
